# R&D: 36장 전체 적층 보드

상태: 실험 적용. 사용자 요청 시 이전 자유 패 버전으로 복귀 가능.

## 비교

| 항목 | 변경 전 | 실험안 |
|---|---|---|
| 적층/자유 패 | 30 + 6 | 36 + 0 |
| 첫 챕터 층 구성 | 15 / 9 / 6 | 18 / 12 / 6 |
| 패 크기 (720×1280 기준) | 92×116 | 108×136 |
| 보드 영역 높이 | 440 | 626 |
| 하단 자유 패 트레이 | 있음 | 없음 |
| 콤보 팝업 | 보드 하단 부근 | 확대 보드 아래 점수 영역 |

점수, 콤보, 초기 40초, 성공 +8초, 셔플 보너스, 부활, 36장 단위 챕터는 변경하지 않았다.
자유 패가 사라져 선택 가능한 숫자가 달라지므로 체감 난이도와 셔플 빈도를 플레이로 비교해야 한다.
생성 보드의 전체 해결 경로는 검증하지만, 임의의 모든 플레이 순서가 끝까지 풀리는 것은 보장하지 않는다.

## 백업 / 롤백

`before/`에 이번 변경 대상 8개 파일과 해당 Unity .meta를 원래 경로대로 보관했다.
`baseline-manifest.json`은 원본 SHA-256 목록이다. 런타임 코드와 설정은 이번 작업 전 상태를 기준으로 한다.
게임 설정 asset, 씬, 아트 리소스는 이번 실험에서 변경하지 않는다.
`Assets` 밖의 백업이므로 Unity에서 백업 C# 파일을 중복 컴파일하지 않는다.

Unity Play를 중지한 상태에서 `RestoreBaseline.ps1`을 실행하면 해시를 확인하고 복구 대상만 보여준다.
실제로 복구할 때만 `-Apply`를 붙인다. 적용 전 현재 파일도 `pre-restore-<id>/`에 보관한다.
기존 아트/결제 데이터 및 다른 파일은 삭제하지 않는다. 적용 후 Unity Refresh와 테스트가 필요하다.
백업 이후 같은 파일에 추가된 수정도 덮어쓰므로, 후속 작업이 쌓인 경우에는 diff 검토 후 선택적으로 복구한다.
