## 실행

홈의 PLAY 버튼으로 시작한다. 마우스 클릭과 모바일 터치가 동일한 UGUI 버튼을 사용한다.

## 구현된 규칙

- 홈 화면: 숲속 유적/TEN 로고와 거대한 `10` 석조 구조물 배경, 기기에 저장된 최고 점수, PLAY/RANKING/STORE/HOW TO 아이콘 버튼. 기존 세 숫자 패와 긴 설명 대신 `3 Touch, Make 10!`를 표시한다. `3`은 노랑, `10`은 빨강이며 글자별 파도 연출을 반복한다. 우측 설정에서 홈 문구 모션을 켜고 끌 수 있고, 기록 버튼에서 기기 최고 점수 및 랭킹 화면으로 이동한다. 설정은 현재 세션에 적용한다. 새 배경은 `HomeRuinsMonument.png`이며 이전 `HomeRuins.png` 원본도 보존한다.
- 글자·숫자는 Noto Sans Bold SDF와 전용 아웃라인 머티리얼을 사용한다. 도트 배경·패널·아이콘과 이전 배경 원본은 유지한다. 밝은 글자는 짙은 초록, 어두운 숫자·버튼 글자는 아이보리 외곽선을 사용한다. 폰트 및 머티리얼은 `Assets/Resources/Fonts/`에 있다.
- 홈의 금색 도트 트로피 랭크 버튼에서 랭킹 UI를 연다. 전체/한국/미국/일본/중국 탭과 뒤로가기를 제공한다. 서버 연동 없이 빈 순위 목록과 로컬 최고 점수만 표시하며, 로컬 점수를 세계 순위로 표시하지 않는다. 한글은 내장 Noto Sans CJK KR의 SDF 폴백을 사용하며 OS 폰트에 의존하지 않는다. 실제 모바일 기기의 표시 상태는 별도 검증이 필요하다.
- R&D 실험: 자유 패 없이 36장 전체 적층. 1챕터는 18/12/6장의 세 단을 엇갈려 쌓는다.
  화면 좌표의 사각형 겹침으로 윗패를 판정하며, 겹치는 윗패가 모두 제거되어야 선택 가능하다.
  그림과 판정은 동일한 X/Y 및 크기를 사용한다. 높은 챕터에서도 총 36장과 층별 3의 배수를 유지한다.
  하단 자유 패 영역을 제거하고 보드 높이 626, 패 크기 108×136으로 확대했다.
  변경 전 백업과 롤백 안내는 `RND/2026-11-01-no-free-tiles/README.md`를 참고한다.
- 세 번째 터치에만 계산. 합이 10이 아닌 실패 조합은 남은 시간에서 3초를 차감하고 선택을 모두 해제한다.
  패는 제거하지 않으며 점수도 차감하지 않는다. 페널티는 `GameBalance.MissPenalty`로 조정한다.
  시간은 0초 아래로 내려가지 않으며, 0초가 되면 첫 사망은 부활 선택, 부활 후 사망은 게임 종료로 즉시 전환한다.
  차감된 3초를 실제 생존 시간에 더하지 않는다.
- 선택한 패를 재터치하면 해당 패 선택을 취소한다. 빈 공간을 클릭하거나 터치하면 전체 선택을 취소한다.
  취소에는 시간·점수 페널티가 없으며 가려진 패 클릭은 무시한다. 패/메뉴 버튼 클릭은 빈 공간 취소로 처리하지 않는다.
- 1~2챕터는 1~9만 등장. 3챕터부터 0과 −1, 5챕터부터 ×2 등장. 순서에 따른 ×2 계산, ×2 첫 선택/중복 사용 금지.
- 3챕터부터 새 보드마다 0과 −1을 각각 최소 1장, 5챕터부터 ×2도 최소 1장 보장한다. 기존 특수 패가 있는 조합을 보호한 뒤, 빠진 종류만 해결 경로의 다른 조합 전체를 교체해 추가한다. 전체 해결 경로와 36장 수량을 유지한다.
- 성공 조합 1회마다 기본 10점과 +3초. 시작 30초, 부활 30초, 최대 부활 1회.
  자동 셔플 완료 시 +8초, 챕터 클리어 추가 시간은 0초이며, 남은 시간의 상한은 90초다.
- 특수 패 색상: 0 노랑, −1 파랑, ×2 빨강. 성공 조합에 0 또는 −1이 있으면 점수 보너스 ×2, ×2 패가 있으면 ×4를 콤보 점수에 곱한다. 혼합 조합은 높은 보너스만 적용하며 추가 시간은 +3초다. 특수 성공은 금빛/푸른 도트 폭죽, ×2 패 성공은 더 크게 퍼지는 붉은 다중 폭죽을 표시한다. 콤보 배지는 특수 점수 보너스와 별도로 현재 콤보 배율만 표시한다.
- 이전 성공 후 3초 미만에 다시 성공하면 ×1.5 → ×2 → ×2.5 → ×3 → ×4 → ×5까지 증가하고 유지한다.
  첫 성공은 ×1이며 각 성공 시 3초를 갱신한다. 특수 보너스가 없는 조합의 점수는 10, 15, 20, 25, 30, 40, 50, 50…점이다.
  3초가 소진되면 초기화한다. 실패 조합은 남은 게임 시간만 3초 차감하며, 점수와 기존 콤보 창을 갱신하지 않는다.
  실패나 선택 취소가 콤보 타이머를 별도로 차감하지는 않는다. 단, 실패 페널티로 사망하면 콤보를 초기화한다.
  일시정지/보드 전환/셔플은 콤보 시간도 정지한다. 사망은 콤보를 초기화하지만 누적 점수는 유지한다.
  시간바 바로 아래의 보라색 콤보 바 길이로 콤보 잔여시간을 표시한다. 별도 조합식은 표시하지 않는다.
  왼쪽의 둥근 배지는 세로 중앙을 지나는 콤보 슬라이더 앞에 겹쳐 현재 배율을 표시한다. 콤보 바를 16픽셀 내려 시간바와 간격을 확보하며 최대 배율 표기는 `×5!!`다.
  ×1/×1.5는 아이보리, ×2/×2.5는 녹색, ×3 파랑, ×4 노랑, ×5 빨강이다. 콤보 바는 보라색을 유지한다.
  첫 성공과 배율 상승 시 배지가 최대 1.16배로 확대됐다 0.36초 안에 복원된다. 콤보 만료·새 게임은 아이보리 `×1`로 돌아간다.
  기존의 큰 획득 점수/배율 팝업은 배지와 중앙 점수 연출로 대체했다. 배지는 입력을 차단하지 않는다.
- 챕터 시작 시 배치된 패를 모두 제거해 보드가 비면 해당 챕터 클리어. 전환이 끝나 새 보드를 배치할 때 챕터가 1 증가한다. 현재 첫 보드는 36장이며, 누적 제거량으로 챕터를 계산하지 않는다. 점수와 진행 중인 콤보는 유지한다.
- 플레이 화면 상단 중앙에 현재 CHAPTER를 표시한다. 마지막 패의 제거 연출 후 CLEAR 팝업을 표시하고 CONFIRM을 눌러야 새 챕터를 시작한다. 대기 중 시간과 콤보는 정지하며 자동 셔플은 기존처럼 자동 진행한다.
- 타이머/콤보 바 아래에는 SCORE 문구 없이 현재 점수 숫자만 크게 노란색으로 중앙 정렬한다.
  점수가 증가하면 최대 1.14배로 확대됐다 0.36초 안에 원래 크기로 돌아온다. 연속 득점은 연출을 다시 시작하며 새 게임은 초기화한다.
  챕터 바로 아래의 `3 Touch, Make 10!`는 글자별 최대 1.22배 스케일 파도를 3.6초 간격으로 반복한다. `3`은 노랑, `10`은 붉은색이다.
  하단의 제거 수 표시는 없애고 최고 점수만 42 크기의 Noto Sans로 중앙 정렬한다. 중앙 점수 60, 타이머 64, 숫자 패 56, 안내 문구는 로비 36·게임 28 크기다. 패 하단의 선택 순서 번호는 표시하지 않는다.
  시간바 채움 높이는 22, 콤보 바는 14(성공 직후 최대 16) UI 픽셀이다.
  시간바는 해당 생명의 시작 시간(기본 30초)을 기준으로 채우며, 2/3 초과 녹색·1/3 초과 노랑·1/3 이하 빨강이다.
  기본 설정에서는 20초 초과 녹색, 10초 초과~20초 노랑, 10초 이하 빨강이다. 성공으로 시간이 늘면 색도 복원된다.
  시작 시간 이상이면 바는 가득 찬 상태를 유지하고 초 단위 숫자는 실제 잔여시간을 표시한다. 최대 잔여시간 설정(현재 90초)은 그대로 적용한다.
- 마지막 조합 완성 시 보드에 큰 도트 폭죽, 클리어 팝업 등장 시 테두리 주변에 추가 폭죽을 표시한다. 각각 다섯 번의 시차 폭발로 구성되며 입력을 막지 않고 자동 소멸한다. 다음 챕터 진입 시 남은 폭죽을 정리한다.
- 실제 생존한 시간만 합산. 사망 프레임 초과분, 메뉴, 광고, 선택 대기, 전환, 셔플, 백그라운드 시간 제외.
- 자동 셔플은 남은 값 재배치를 먼저 시도하고 BoardSolver가 전체 해결 경로를 확인한다.
- 일반 생성은 전체 해결 경로를 구성한다. 생성 경로의 유효성은 EditMode 테스트에서 검사한다. 확률은 유효 조합 조건부 표본과 특수 패 최소 수량 보장으로 보정되므로 원래 목표 가중치와 실측 비율은 달라진다.
- 순수 숫자/게임 모델과 UI, 광고, 구매, 저장 구현을 분리했다.

## 셔플 복구의 경계

유한한 숫자 재배치/탐색으로 해를 찾지 못하면 현재 위치에서 해결 가능한 숫자 조합을 구성한다.
선택 가능한 패가 3장 미만이 되는 등 적층 구조가 막혔으면 남은 패의 위치와 층도 다시 정렬한다.
새 배치는 3장 단위로 제거 가능한 작은 적층 보드이며, 기존 숫자로 전체 해를 찾을 수 있으면 유지한다.
숫자 조합도 불가능하면 값을 다시 구성해 끝까지 풀 수 있는 경로를 보장한다.
패 ID와 남은 장수, 제거 상태, 점수, 챕터, 부활 상태는 유지한다. 막힘 때문에 게임을 종료하지 않는다.
복구 중 시간과 콤보는 정지하며 기존 셔플 보너스는 한 번만 지급한다.

## 부활권

부활 선택 화면은 `ONE MORE LIFE?` 제목, 보드 유지·부활 시간 안내, 현재 점수와 사각 아이콘 3개를 표시한다.
로비와 같은 도트 프레임을 사용하며, 가로로 WATCH AD(영상 재생), FINISH(체커 깃발), REVIVE PASS(하트 티켓)를 배치한다.
광고/부활 버튼은 금색 테두리와 밝은 초록색으로 강조한다. 기존 생존 시간 정지 안내 문구는 표시하지 않는다.
사용 가능한 부활권이 있으면 첫 아이콘은 USE TICKET과 남은 수량으로 바뀐다. MOCK 표시는 테스트 서비스에만 붙인다.
부활 패스에서 상점을 열었다 돌아와도 보드·점수·부활 선택 상태는 유지한다. 부활 시간 안내는 `GameBalance.ReviveTime`을 따른다.

ReviveTicketManager는 HasAdFreeRevivePurchase, CurrentTicketCount, LastResetDate를 저장한다.
DailyTicketAmount=2, MaxTicketCount=2, ResetTimezone=Asia/Seoul.
서버가 확인한 날짜가 증가했을 때만 2장으로 덮어쓴다. 이월/누적 없음.
동일 날짜 복원/재실행/재요청에 재지급하지 않는다. 과거 서버 날짜 응답은 거부한다.
시각 조회 실패 또는 저장 실패는 RecheckRequired로 처리하며 소비/지급을 보류한다.
동시 호출은 직렬화하고 같은 실행 ID에 대한 연속 중복 차감을 거부한다.
최초 접속, 앱 복귀, 30초 주기, 구매/복원 및 소비 직전에 서버 시각을 재확인한다.
소비 저장을 성공시킨 후에만 UI가 부활을 실행한다. 단말기 DateTime.Now/UtcNow를 사용하지 않는다.

## Mock과 실제 연동의 구분

이 버전은 명세의 “실제 계정이 필요한 기능은 Mock을 먼저 구현” 원칙에 따른 프로토타입이다.
실제 광고 SDK, 스토어 SDK, 영수증 검증 서버, 인증/서버 저장소는 아직 연결되지 않았다.
Mock 상태는 UI에 명시하며 실제 결제는 일어나지 않는다. 표시된 9,000원은 명세의 참고 가격이다.

- MockServerClock: 독립적인 고정 테스트 시각(2026-10-31 23:59 KST) + 단조 증가 경과시간.
  실제 신뢰 서버가 아니다. 재실행 시 테스트 시각은 원점으로 돌아간다.
  LAB의 +1 DAY로 전날 잔액 초기화를, ONLINE/OFFLINE으로 재확인 보류를 시험한다.
  저장된 초기화 날짜가 이 테스트 시각보다 미래이면 정상적으로 지급을 보류한다.
- MockPurchaseGateway: 별도 PlayerPrefs 키로 비소모성 상품의 Mock 소유권을 보관한다.
  구매와 복원 모두 검증 결과 인터페이스를 거쳐 지급한다.
- MockRewardedAdService: 완료/취소/로드 실패를 LAB에서 선택한다. 완료에만 부활한다.
- EnableMockCommerce=false: 외부 서비스 미연결 상태로 명시적으로 실패한다. 기기 시각으로 대신 지급하지 않는다.
- LocalRanking: 기기 내 최고 점수를 저장한다. 글로벌 랭킹 서버는 아니다.
  점수 키는 `.Prototype.BestScore.v1`이며 과거 `.Prototype.BestSeconds`는 점수로 변환하거나 읽지 않는다.

출시 전에 ITrustedServerClock / IPurchaseGateway / IRewardedAdService를 실제 어댑터로 교체해야 한다.
IPurchaseGateway는 계정에 연결된 서버에서 스토어 영수증, 상품 ID, 환불/취소 상태를 검증해야 한다.
서버 시각은 인증된 HTTPS 백엔드에서 신선도를 확인한 응답이어야 한다.
PlayerPrefs는 프로토타입 저장이며 변조 방지 수단이 아니다. 실제 운영에서는 일일 초기화/잔액/소비를
서버의 원자적 트랜잭션과 runId 멱등 키로 처리해야 재설치, 여러 기기, 응답 유실까지 안전하다.
Android 로컬 APK는 2026-11-02 최신 로비 및 게임 UI를 포함해 빌드했다. 파일은 `Builds/Android/THE-TEN-Local.apk`에 있으며
서명·정렬·패키지 정보를 검증했다. 상세 결과는 `Documentation/Android-local-build.md`와 `Documentation/Validation.json`의 `androidLocalApk`를 참고한다.
실제 Android 기기 설치·실행, iOS 기기 빌드 및 스토어 샌드박스 검증은 아직 수행하지 않았다.

## 아직 확정되지 않은 항목

MaxRemainingTime=90, BoardClearBonus=0은 임시값이다. 광고 로드 실패 시 기본 정책은 부활 선택 화면 유지다.
파일로 전달된 v3.0 원문은 10.4의 “구매 상태 저장”에서 끝난다.
별도의 스킨 상품 명세/가격, 글로벌 랭킹 규약, 후반부 명세는 제공되지 않아 임의 확정하지 않았다.
