# 0. Codex 개발 지시

본 문서를 기반으로 모바일 퍼즐게임 THE TEN!을 개발한다.

목표는 단순한 화면 목업이 아니라 **실제로 플레이할 수 있는 게임 프로토타입을 완성하는 것**이다.

### 개발 기본 원칙

1. Unity 6.3을 사용한다.
2. Android와 iOS를 지원할 수 있도록 설계한다.
3. 세로 화면과 터치 조작을 기본으로 한다.
4. 2D 기반으로 개발하되 마작패의 입체적인 두께와 적층 표현을 구현한다.
5. 게임 규칙, UI, 데이터, 광고, 결제 시스템을 분리한다.
6. 밸런스 수치는 ScriptableObject에서 수정 가능하도록 한다.
7. 외부 유료 에셋 없이 기본 프로토타입을 제작한다.
8. 기존 프로젝트가 존재하면 먼저 분석하고 필요한 부분만 수정한다.
9. 컴파일 오류가 없는 상태를 유지한다.
10. 실제 광고 및 결제 계정이 필요한 기능은 Mock 시스템을 먼저 구현한다.

미확정 항목은 임의로 최종 확정하지 말고 설정값으로 분리한다.

# 1. 게임 개요

## 1.1 핵심 콘셉트

THE TEN!은 사천성·마작 솔리테어의 시각적 구조를 활용한 숫자 조합 퍼즐게임이다.

여러 층으로 쌓인 숫자 패 중 선택 가능한 패 3개를 터치하여 최종 계산 결과를 10으로 만든다.

성공하면 패가 제거되고 남은 시간이 8초 증가한다.

제한시간이 0초가 될 때까지 플레이하며, 한 판에 최대 두 번의 생존 기회가 주어진다.

두 생존시간의 합계로 랭킹을 경쟁한다.

## 1.2 게임 핵심 요소

- 숫자 10 만들기
- 3회 터치
- 사천성 스타일의 적층 보드
- 시간 제한 생존
- 패 제거 및 아래층 개방
- 자동 셔플
- 챕터별 신규 숫자와 연산
- 광고를 통한 부활
- 생존시간 랭킹
- 유료 카드 스킨

# 2. 핵심 게임 규칙

## 2.1 기본 조작

플레이어는 선택 가능한 패를 세 번 터치한다.

첫 번째 터치: 첫 번째 패 선택

두 번째 터치: 두 번째 패 선택

세 번째 터치: 세 번째 패 선택 및 최종 계산

세 번째 패를 선택한 시점에만 계산 결과를 판정한다.

## 2.2 성공 조건

최종 계산 결과가 정확히 10이면 성공한다.

예시:

- 2 + 3 + 5 = 10
- 1 + 4 + 5 = 10
- 7 + 2 + 1 = 10

성공 시 다음 처리를 실행한다.

- 선택한 패 3개 제거
- 남은 시간 +8초
- TEN! 성공 연출
- 누적 제거 패 개수 +3
- 성공 횟수 +1
- 가려진 패의 선택 가능 상태 갱신
- 보드 클리어 여부 검사
- 챕터 진행도 갱신
- 유효 조합 존재 여부 검사

## 2.3 실패 조건

세 번째 터치 이후 계산 결과가 10이 아니면 실패한다.

실패 시:

- 선택된 패 3개 해제
- 패 제거 없음
- 시간 페널티 없음
- 추가적인 불이익 없음

단, 실제 플레이 중이므로 타이머는 계속 흐른다.

## 2.4 선택 취소

선택된 패를 다시 터치하면 선택을 취소한다.

동일한 패를 한 조합에서 중복 선택할 수 없다.

선택 불가능한 패를 터치하면 입력을 무시한다.

## 2.5 콤보 시스템

**콤보 시스템은 사용하지 않는다.**

연속 성공 횟수에 따른 추가 보상은 없다.

모든 정상적인 성공 조합에 동일하게 +8초를 지급한다.

# 3. 보드 시스템

## 3.1 보드 기본 구성

한 보드는 총 60장의 패로 구성한다.

| 구분 | 패 개수 |
|---|---:|
| 적층 패 | 54장 |
| 자유 패 | 6장 |
| 전체 | 60장 |

패는 보드 생성 시 모두 배치된다.

게임 도중 새로운 패가 자동 보충되지 않는다.

## 3.2 사천성 스타일의 비주얼

보드는 사천성·마작 솔리테어와 유사한 적층 구조를 사용한다.

중요한 특징은 다음과 같다.

- 패는 직사각형 마작패 형태다.
- 패에 두께가 존재한다.
- 여러 층으로 겹쳐 배치된다.
- 위층 패는 아래층 패와 약간 어긋난다.
- 아래층 패의 가장자리와 숫자 일부가 보인다.
- 패의 그림자와 측면으로 깊이를 표현한다.
- 위층 패를 제거하면 아래층 패가 드러난다.

단순한 평면 그리드 UI로 구현하지 않는다.

## 3.3 적층 규칙

적층 패는 서로 겹쳐 배치된다.

위쪽 패가 아래쪽 패를 가리고 있으면 아래 패는 선택할 수 없다.

가려진 패의 숫자가 일부 보이더라도 선택은 불가능하다.

해당 패를 가리는 모든 패가 제거되면 선택 가능 상태가 된다.

패 제거 후 다른 패들은 이동하지 않는다.

## 3.4 자유 패 영역

보드 하단에 자유 패 6장을 별도로 배치한다.

자유 패는 다른 패에 가려지지 않는다.

따라서 언제든 선택할 수 있다.

적층 패와 자유 패를 조합하여 3개를 선택할 수 있다.

자유 패도 보드 전체 60장에 포함되므로 제거 후 자동 보충되지 않는다.

## 3.5 보드 클리어

60장의 패가 모두 제거되면 보드를 클리어한다.

이후 새로운 보드가 등장한다.

다음 정보는 유지한다.

- 현재 남은 시간
- 총 생존시간
- 현재 챕터
- 누적 제거 패 개수
- 성공 횟수
- 부활 사용 여부

보드 교체 중에는 타이머를 일시정지한다.

# 4. 챕터 시스템

## 4.1 진행 조건

챕터는 누적 제거 패 개수를 기준으로 진행한다.

**패 60장을 제거할 때마다 챕터가 1 증가한다.**

계산식:

Chapter = floor(TotalRemovedTiles / 60) + 1

보드 클리어와 챕터 증가는 별개의 시스템으로 구현한다.

현재 설정에서는 보드가 60장이므로 정상적으로 보드를 전부 제거할 때마다 챕터도 하나 증가한다.

## 4.2 적층 높이

| 챕터 | 최대 적층 높이 |
|---|---:|
| 1~9 | 3층 |
| 10~19 | 4층 |
| 20~29 | 5층 |
| 30~39 | 6층 |
| 40~49 | 7층 |

이후 10챕터 단위로 최대 적층 높이가 1층 증가한다.

단, 실제 모바일 화면의 가독성을 고려하여 최대 적층 높이 제한값을 별도 설정으로 제공한다.

## 4.3 챕터별 숫자 패 구성

### Chapter 1~9

일반 숫자 1~9만 등장한다.

각 숫자는 동일한 확률을 기본값으로 사용한다.

### Chapter 10~19

일반 숫자 외에 0과 -1이 등장한다.

| 패 종류 | 등장 확률 |
|---|---:|
| 일반 숫자 1~9 전체 | 84% |
| 0 | 8% |
| -1 | 8% |

일반 숫자 1~9는 전체 84%를 균등하게 나눈다.

### Chapter 20 이후

×2 연산 패가 추가된다.

| 패 종류 | 등장 확률 |
|---|---:|
| 일반 숫자 1~9 전체 | 85% |
| 0 | 5% |
| -1 | 5% |
| ×2 | 5% |

일반 숫자 1~9는 전체 85%를 균등하게 나눈다.

패 등장 확률은 보드 생성 시 사용하는 목표 가중치다. 실제 배치 결과는 해결 가능한 보드를 만들기 위한 검증과 재생성 과정에서 조정될 수 있다.

# 5. 특수 숫자 시스템

## 5.1 숫자 0

Chapter 10부터 등장한다.

기본 덧셈 규칙을 사용한다.

예시:

9 + 1 + 0 = 10

## 5.2 숫자 -1

Chapter 10부터 등장한다.

기본 덧셈 규칙을 사용한다.

예시:

9 + 2 - 1 = 10

중간 합계가 10을 초과해도 실패하지 않는다.

## 5.3 ×2 패

Chapter 20부터 등장한다.

×2 패는 일반 숫자가 아닌 연산 패다.

### 첫 번째 터치

×2 패를 선택할 수 없다.

### 두 번째 터치

첫 번째 숫자를 두 배로 만든다.

예시:

3 → ×2 → 4

(3 × 2) + 4 = 10

성공.

### 세 번째 터치

앞서 선택한 두 숫자의 합계를 두 배로 만든다.

예시:

2 → 3 → ×2

(2 + 3) × 2 = 10

성공.

### 추가 규칙

- ×2는 첫 번째 패로 선택 불가
- 한 조합에서 ×2는 최대 한 장만 사용
- 세 번째 터치에서 최종 결과 판정
- 성공하면 ×2 패도 함께 제거
- ×2 패도 전체 패 60장에 포함

# 6. 시간 시스템

## 6.1 기본 규칙

| 항목 | 값 |
|---|---:|
| 최초 시작시간 | 60초 |
| 정상 조합 성공 | +8초 |
| 자동 셔플 성공 | +8초 |
| 부활 후 지급시간 | 30초 |
| 실패 시 시간 페널티 | 없음 |
| 콤보 보너스 | 없음 |

시간은 실제 게임 플레이 중에만 감소한다.

## 6.2 타이머 정지 조건

다음 상황에서는 타이머를 일시정지한다.

- 일시정지 메뉴
- 광고 시청
- 부활 선택 화면
- 보드 교체 연출
- 자동 셔플 연출
- 게임 종료 화면

## 6.3 미확정 시간 설정

다음 두 항목은 최종 확정되지 않았다.

- 최대 보유시간 제한: 기존 테스트 값 90초
- 보드 클리어 추가 보너스: 기존 테스트 값 +5초

프로토타입에서는 각각 `MaxRemainingTime`과 `BoardClearBonus` 설정으로 분리한다.

기본 구현에서는 최대 보유시간 90초, 보드 클리어 보너스 0초를 임시값으로 사용한다. 이 값은 개발 편의를 위한 임시 설정이며 최종 게임 규칙으로 확정하지 않는다.

# 7. 자동 셔플 시스템

## 7.1 발생 조건

현재 선택 가능한 패들 중에서 결과가 10이 되는 3패 조합이 하나도 존재하지 않으면 자동 셔플을 실행한다.

플레이어가 직접 셔플 버튼을 누를 필요는 없다.

## 7.2 셔플 처리

1. 현재 선택 가능한 패 목록 검사
2. 모든 유효한 3패 조합 탐색
3. 유효 조합이 0개면 게임 입력 일시정지
4. AUTO SHUFFLE 연출 표시
5. 남은 패의 숫자와 특수 패 재배치
6. 패의 물리적 위치 및 적층 관계 유지
7. 새로운 유효 조합 검사
8. 정상적인 셔플 완료 시 +8초
9. 게임 재개

## 7.3 필수 예외 처리

자동 셔플이 무한 반복되어서는 안 된다.

따라서 다음 조건을 구현한다.

- 셔플 처리 중 중복 셔플 금지
- 셔플 후 즉시 다시 셔플이 발생하는 무한 반복 방지
- 셔플 보너스 중복 지급 방지
- 선택 가능한 조합 최소 1개 보장
- 가능하면 보드 전체 해결 경로 보장
- 남은 패로 어떤 재배치를 해도 해결할 수 없는 경우의 안전한 복구 처리

패를 무작위로 섞는 것만으로 해결 가능성을 보장할 수 없으므로 BoardSolver가 유효한 해결 경로를 검사해야 한다.

# 8. 생존 및 부활 시스템

## 8.1 생존 기회

한 판의 게임에는 최대 두 번의 생존 기회가 있다.

첫 번째 생존은 60초로 시작한다.

남은 시간이 0초가 되면 부활 선택 화면을 표시한다.

부활에 성공하면 두 번째 생존을 30초로 시작한다.

두 번째 생존에서 시간이 0초가 되면 최종 게임 오버다.

## 8.2 부활 시 유지되는 정보

- 현재 보드
- 남아 있는 패
- 현재 챕터
- 누적 제거 패 개수
- 총 생존시간
- 성공 횟수

부활 시 현재 보드를 처음부터 다시 시작하지 않는다.

## 8.3 생존시간 계산

최종 생존시간은 다음과 같다.

TotalSurvivalTime = FirstSurvivalTime + SecondSurvivalTime

광고 시청 시간, 부활 선택 대기시간, 일시정지 시간, 보드 전환 연출 시간은 제외한다.

부활하지 않고 종료하면 첫 번째 생존시간만 기록한다.

---

# 9. 광고 시스템

## 9.1 보상형 광고

첫 번째 사망 후 보상형 광고를 시청하면 부활할 수 있다.

광고 시청이 정상적으로 완료되어 보상이 확인되면 두 번째 생존 기회를 지급한다.

광고를 거절하면 게임이 종료된다.

광고 시청을 중단하거나 보상을 받지 못하면 부활이 실행되지 않는다.

## 9.2 광고 로드 실패

광고 서버 문제로 광고가 준비되지 않았을 때의 최종 정책은 미확정이다.

프로토타입에서는 테스트 가능한 예외 처리 기능을 구현하고, 운영 정책을 설정값으로 분리한다.

# 10. 광고 없는 부활권 상품

## 10.1 상품 정보

상품명: 광고 없는 부활 패키지

판매 가격: **9,000원**

상품 유형: 비소모성 인앱 결제

한 번 구매하면 영구적으로 구매 상태가 유지된다.

## 10.2 일일 지급

구매자에게 매일 광고 없는 부활권 2장을 제공한다.

| 항목 | 규칙 |
|---|---|
| 일일 지급량 | 2장 |
| 최대 보유량 | 2장 |
| 초기화 | 매일 00:00 |
| 기준 시간대 | Asia/Seoul |
| 미사용 부활권 | 이월 없음 |
| 사용량 | 부활 1회당 1장 |

매일 잔여량을 2장으로 초기화한다.

기존 부활권에 2장을 추가하는 방식이 아니다.

## 10.3 부활권 소진 후

부활권이 모두 소진된 구매자는 일반 무료 이용자처럼 보상형 광고를 시청하고 부활할 수 있다.

구매자와 무료 이용자의 최대 부활 횟수는 동일하다.

한 판에 부활은 최대 한 번이다.

## 10.4 결제 시스템

- 구매 상태 저장
